# Amber Roberts

Consulting and contract work. The motto is "Protect the hours that matter."

This repository has three branches:

- `main` is concierge stationery.
- `acid` is a patchbay for attention.
- `folio` is a private directory.

## Contact address

Open `js/site.js` and set `CONTACT_EMAIL` to a real address. Leave it as an empty string if you do not want a public address.

When the string is a valid email, the contact page adds a mailto link. When it is empty, the page shows a brief you can copy and send yourself.

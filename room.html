Room

A room someone has thought through.

The office should feel considered. That is a working standard, not a mood. People notice when the path is clear and when the current file is easy to find.

Supplies and inventory

She counts supplies and reorders before a drawer runs empty. Inventory lives on a list with an owner, so the room does not depend on memory. A missing pen should not be the thing that stops the day.

The physical room

The room needs a flow. There is a place to arrive, a place to work, and a place for a conversation that should not happen in a doorway. A professional room is clear enough to use. What remains on a surface is there because the work uses it.

Paper and digital files

Digital organization follows the same rule as the furniture. A file has a place, a name, and a person who knows which version is current. The shared drive should feel as considered as the room you walk into. The day depends on this. So does any tool she later allows in.
